# The Other Garage

**Project ideas and build logs for getting better at motorsports design.**  
**The garage you don’t park in.**

This repository is a living collection of project ideas and the stories of how they get built. The focus is practical work that sharpens motorsports design skills — aerodynamics, vehicle dynamics, structures, thermal systems, and integrated performance.

## What’s here

- **[IDEAS.md](IDEAS.md)** — the full catalogue of project ideas, organised by category.
- Category folders — each major area has its own folder.
- Individual project files — once a project is started, it lives as a markdown file inside its category. These capture the idea, process, decisions, results, and lessons.

## How it works

1. New ideas go into [IDEAS.md](IDEAS.md).
2. When a project starts, create a new `.md` file in the relevant category folder.
3. Write the story as you go — assumptions, tools, iterations, failures, and outcomes all belong here.

This is a working garage, not a polished showroom. The process is the point.
